## 项目理念

**女娲造人，我们造角色卡。**

nuwa-skill 蒸馏的是真实人物的思维方式（心智模型、决策启发式、表达 DNA），让 AI 用乔布斯、芒格、费曼的思维方式帮你分析问题。

CastingNuwa 将这一理念迁移到戏剧领域：**蒸馏戏剧角色的 "认知操作系统"**—— 性格特质、核心动机、行为模式、语言 DNA、情感弧线 —— 生成结构化的 "角色卡"，再与演员的多维度画像做智能匹配，辅助导演做出可解释的选角决策。

### 与传统选角的区别



| 传统选角      | CastingNuwa         |
| --------- | ------------------- |
| 导演凭感觉和经验  | AI 系统化分析 + 可解释的匹配建议 |
| 不可复现、不可追溯 | 每个角色卡都有剧本原文证据       |
| 只看试镜表现    | 角色认知深度 + 演员多维度画像    |
| 黑盒决策      | 匹配理由 + 风险提示 + 试镜建议  |

## 功能模块

### ✅ Phase 1：角色蒸馏（Role Distiller）

输入剧本，AI 自动蒸馏所有角色的认知操作系统，生成 7 维度角色卡。

**角色卡 7 维度**：



1. 基本信息 — 身份、年龄性别、出场频率

2. 性格特质 — 3-5 个核心特质，每个附剧本证据

3. 核心动机 — Want / Need / Fear / 动机变化轨迹

4. 行为模式 — 压力 / 冲突下的典型反应，附剧本例子

5. 语言 DNA — 用词、句式、口头禅、语气、身份标记

6. 情感弧线 — 开场状态 → 转折点 → 结尾状态 + 弧线类型

7. **选角指引** — 适合演员类型、核心能力要求、试镜重点、风险提示、化学反应要求

### ✅ Phase 2：演员画像（Actor Profiler）

输入演员材料（自我介绍 + 试镜片段），AI 生成 7 维度演员画像。

**支持三种输入模式**：
- 📝 **文本模式**：粘贴自我介绍和试镜转写文本
- 🎵 **音频模式（双模态）**：上传试镜音频 → Whisper 语音转写 + 声学特征分析（音高/音色/语速/韵律）+ LLM 融合分析
- 🎥 **视频模式（三模态）**：上传试镜视频 → 音频分析 + MediaPipe 视觉分析（面部表情/肢体语言）+ LLM 三模态融合

**演员画像 7 维度**：



1. 基本信息 — 年龄性别、表演经验、背景

2. 声线特质 — 音高、音色、清晰度、语速节奏、情感表达、优势 / 局限

3. 面部表现力 — 表情幅度、微表情控制、眼神传达

4. 肢体表现力 — 手势丰富度、姿态自然度、空间使用、移动流畅度

5. 情感表达范围 — 能表达的情感种类、情感深度、转换流畅度、最擅长 / 较弱

6. 气质类型 — 主要 / 次要气质、整体印象、适合 / 不适合的戏剧类型

7. 表演风格与潜力 — 风格倾向、自然度、节奏感、台词功底、潜力评估、发展建议

### ✅ Phase 3：匹配引擎 + Web 界面（Matching Engine + Web UI）

将角色卡与演员画像进行多维度匹配，输出匹配度评分、匹配理由、风险提示和试镜建议。

**匹配 6 维度**：



1. 性格与气质匹配

2. 动机与情感深度匹配

3. 语言与台词匹配

4. 行为与肢体匹配

5. 表演风格匹配

6. 潜力与可塑性

**输出**：



* 综合匹配度（0-100 分）+ 匹配等级

* 分维度评分（带进度条）

* 匹配优势、风险提示、试镜建议

* 全量匹配矩阵（角色 × 演员热力图）

* 推荐汇总（每个角色的最佳匹配演员）

## 快速开始

### 1. 安装依赖



```
pip install -r requirements.txt
```

> 核心依赖：
>
> `openai`
>
> （LLM 调用）、
>
> `gradio`
>
> （Web 界面）。
> 不安装也能运行 CLI（会进入 Mock 演示模式），但 Web 界面需要 gradio。

### 2. 配置 LLM API（可选）

复制 `.env.example` 为 `.env`，填入你的 API 信息：



```
cp .env.example .env
```

支持所有 OpenAI 兼容 API：DeepSeek、智谱 GLM、豆包、通义千问、OpenAI 等。

> 不配置 API 也能运行，程序会自动进入 
>
> **Mock 演示模式**
>
> ，使用预设的示例数据，方便体验完整流程。

### 3. 启动 Web 界面（推荐）



```
python app.py
```

浏览器会自动打开 `http://127.0.0.1:7860`，界面包含 4 个标签页：



1. **📝 角色蒸馏** — 粘贴剧本 → 生成角色卡

2. **🎬 演员画像** — 粘贴演员材料 → 生成演员画像

3. **🎯 智能匹配** — 选择角色和演员 → 匹配分析 / 全量匹配

4. **ℹ️ 关于** — 项目说明

### 4. 命令行使用



```
\# 角色蒸馏（全角色）

python main.py --script examples/sample\_script.txt --summary

\# 角色蒸馏（单角色深度）

python main.py --script examples/sample\_script.txt --role "莱恩" --summary

\# 指定输出路径

python main.py --script my\_script.txt --output output/my\_result.json
```

## 技术架构

### 四 Agent 蒸馏流水线（对标 nuwa-skill）



| Agent                         | 职责                 | 状态    |
| ----------------------------- | ------------------ | ----- |
| **角色蒸馏器** (Role Distiller)    | 剧本 → 角色卡（7 维度深度分析） | ✅ 已实现 |
| **演员画像器** (Actor Profiler)    | 演员材料 → 多维度演员画像     | ✅ 已实现 |
| **选角导演** (Casting Director)   | 角色卡 × 演员画像 → 匹配报告  | ✅ 已实现 |
| **主合成器** (Master Synthesizer) | 汇总 → 结构化选角报告       | ✅ 已实现 |

### 技术栈



* **LLM 推理**：OpenAI 兼容 API（DeepSeek / 智谱 GLM / 豆包 / 通义千问等）

* **Web 界面**：Gradio 4.x

* **数据模型**：Python dataclass + 结构化 JSON

* **Prompt 工程**：结构化引导 + 证据约束 + JSON 强制输出

* **后续规划**：Whisper（语音）、MediaPipe/OpenCV（视觉）、sentence-transformers（向量匹配）

## 常见问题

### Q: 没有 API Key 能用吗？

A: 可以。程序会自动进入 Mock 演示模式，使用预设的示例角色卡和演员画像，方便体验完整流程。配置 API 后可使用真实 AI 分析。

### Q: 支持哪些 LLM？

A: 所有 OpenAI 兼容 API，包括 DeepSeek、智谱 GLM、豆包、通义千问、OpenAI 等。在 `.env` 中配置 `LLM_BASE_URL` 和 `LLM_MODEL` 即可。

### Q: 演员画像支持视频 / 音频输入吗？

A: 当前版本（v0.3）支持三种输入模式：文本模式、音频模式（双模态：Whisper转写+声学特征）、视频模式（三模态：音频+MediaPipe视觉分析）。Web 界面的演员画像标签页提供了这三种模式的子标签页。

### Q: 匹配准确度如何？

A: 匹配基于 LLM 对角色卡和演员画像的深度理解，准确度取决于模型能力和输入材料质量。每个匹配结果都附带具体的匹配理由和风险提示，导演可以结合自身经验做出最终决策。AI 是辅助工具，不是决策者。

### Q: 如何导出结果？

A: Web 界面中每个模块都提供 JSON 输出，可直接复制保存。命令行模式下结果自动保存为 JSON 文件到 `output/` 目录。
