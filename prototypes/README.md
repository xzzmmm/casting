# Theatre production prototypes

Each directory contains its own setup instructions and dependencies.

| Prototype | Scope |
| --- | --- |
| [DramaScheduler](drama-scheduler/) | Build a rehearsal schedule from an availability workbook and rehearsal requirements. |
| [StageMind](stagemind/) | Capture rehearsal notes and blocking, with optional transcription and pose analysis. |
| [ScriptDoc and SerialDoc](scriptdoc/) | Run ScriptDoc’s rule-based script diagnosis and browse the SerialDoc series-script proposal. |
