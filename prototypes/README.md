# Theatre production prototypes

Each directory contains setup instructions and a `share/` folder. Download or
clone the repository, then open the `share/index.html` file in a browser.

| Prototype | Scope | Offline demo |
| --- | --- | --- |
| [DramaScheduler](drama-scheduler/) | Build a rehearsal schedule from an availability workbook and rehearsal requirements. | [share](drama-scheduler/share/) |
| [StageMind](stagemind/) | Capture rehearsal notes and blocking, with optional transcription and pose analysis. | [share](stagemind/share/) |
| [ScriptDoc and SerialDoc](scriptdoc/) | Run ScriptDoc’s rule-based script diagnosis and browse the SerialDoc series-script proposal. | [share](scriptdoc/share/) |
