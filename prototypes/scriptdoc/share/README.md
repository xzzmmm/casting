# ScriptDoc 离线演示

下载项目后，用浏览器直接打开 [index.html](index.html)。先选场次，再按角色筛选对白。点选一行可查看前后对白、附近舞台提示、排练笔记和规则命中证据。舞台提示与未归属原文在「全部角色」中可查看。

三个合成示例使用 Python 规则引擎预先生成分数，排练笔记根据示例对白和舞台提示编写。两组夸张台词相同，改变角色和场景后，场景分数由 61.8 调整为 28.5。

要分析新文本，按[项目启动说明](../README.md)运行 FastAPI，再打开 `http://127.0.0.1:8000/` 粘贴剧本。可以用「第一幕」「第一场」「角色：台词」和「【舞台提示】」标明结构。

[SerialDoc](../SerialDoc_剧集剧本诊断项目方案.html) 记录连续剧诊断方案。
