# DramaScheduler

DramaScheduler 读取成员的可用时段和排练任务，用 OR-Tools CP-SAT 生成日程。它检查必到成员的可用性、排练次数和每日时长上限，并提供周历、进度和 CSV 导出。

## 本地运行

在本目录使用 Python 3.10 或更新版本。

```sh
python -m pip install -r requirements.txt
python main.py
```

打开浏览器访问 `http://127.0.0.1:8000`，上传 [合成示例](examples/template-v2.xlsx)，确认任务时长、次数及优先级，然后排期并导出 CSV。示例使用八个虚构姓名。

## 输入格式

- **模板 v2**（XLSX、XLS 或 UTF-8 CSV）。前五列填写成员姓名、职位/角色、所属组别、参与任务（场次）和关键人物，随后按顺序填写周一早、周一午、周一晚等时段。`V` 表示可用，`NA` 表示不可用。
- **按日期分列**（XLSX）。第一张工作表的首列表头分别为 `Date` 和 `Session`，随后每行填写一名成员及各时段的可用性。一次读取第一个表块，时段列从左至右排列。成员可用 `姓名-职位` 标注角色。默认任务按导演、舞监、ASM、制作人和技术岗位匹配必到人员。部分出席按可用近似处理，页面会显示提示。

应用面向本地单用户试用。CSV 接口导出本次服务进程内最近一次成功的排期。
